# Папка для картинок ассоциаций

Здесь нужно разместить следующие файлы:

1. **arcane.jpg** - Аркейн (логотип или Паудер)
2. **daen.jpg** - Даен (персонаж в зелёной кофте и очках)
3. **dandelions.jpg** - Одуванчики (жёлтые цветы)
4. **red-inferno.jpg** - Темно красный цвет (#4E0000)
5. **storm.jpg** - Ночь с грозой (молнии в облаках)
6. **fruits.jpg** - Фрукты (апельсин, клубника, киви, черника)

## Как загрузить картинки:

1. Клонируй репозиторий
2. Добавь картинки в папку `/assets/`
3. Убедись, что имена файлов точно совпадают с указанными выше
4. Коммит и push

Размеры: рекомендуется 400x300px или больше для лучшего качества.
